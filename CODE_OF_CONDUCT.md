# Code of Conduct

Status OS exists to benefit humans through better machine continuity, hardware preservation, and open collaboration.

Contributors are expected to:

- be respectful,
- be precise,
- avoid harassment,
- assume sincere intent where reasonable,
- keep debate technical and constructive,
- protect users and contributors,
- avoid exclusionary conduct,
- respect privacy and security boundaries.

Unacceptable conduct includes:

- harassment,
- threats,
- doxxing,
- malicious code,
- knowingly unsafe advice,
- attempts to capture the project for exploitation,
- repeated bad-faith disruption.

Reports should be handled by project maintainers or appointed community stewards.

This file should be replaced or expanded with a formal Contributor Covenant-compatible policy before large public launch.
